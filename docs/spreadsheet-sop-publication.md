# Spreadsheet SOP 出版

正式出版模块使用 Python `openpyxl` 和必要的 OOXML 处理，只接收已通过确定性
图片硬门的步骤结果。它不规划步骤、不运行 Creo，也不能把失败图片升级为通过。

## 分页与交付

- 以主工序分组，同一主工序允许包含多张安装图；
- 超出单页容量时自动创建“主工序名称-续页”；
- 不假定 8 个工序、固定工作表数量或两位编号；
- 待确认工作簿使用推荐候选，并显示醒目的“待确认”提示；
- 正式交付目录严格限定为 `SOP.xlsx`（或 `SOP_待确认.xlsx`）和 `步骤图片/`。

第一版使用代码内置的标准版式，不开放任意模板。生成后的工作簿先由 `openpyxl`
复核工作表、图片关系和打印区域；Windows 正式运行再由普通版 Excel COM 只读打开，
临时导出 PDF 做最终检查。临时 PDF、检查图、JSON 与日志均留在 Agent 内部。

旧的 Node 和 `@oai/artifact-tool` 出版脚本已从正式路径删除。
