# 单图自动取景

用户要求：仅明确要求时做全量测试，其余只做小批量；放弃定位图与详图双图，每个测试步骤统一一张图。

当前实现复用原生选中对象取景与接口法向斜视角。读取 moving_bounds、context_bounds 的并集尺寸，按承接件/待装件尺寸比例计算有限外扩：

`expansion = clamp(1.35 + 0.25 * log2(max(receiver_span / max(moving_span, 1), 1)), 1.35, 2.4)`

`zoom_to_selected_level = 0.85 / expansion`

离散待装件使用包围盒并集，保留完整分组，不减少数量。大长件继续按原生接触曲面取景。外扩在 Creo 内完成，不做图片自适应裁切，不调用 GPT，不多渲染候选图。旧冻结任务不改变。

局限：包围盒只能决定留白范围，尚不能证明留白内的结构足够独特，也没有实现遮挡评分。宽大的接触曲面或离散连接点仍可能使细节偏小。需要实机小样本校准，不宣称所有场景可读性已通过。

本次完成 16 个样本，保留原分组，覆盖根装配及 1–4 层范围。2026-10-10 修正许可预检只比较第一网卡的误判：允许核对系统实际安装的其他网卡，Creo 原生许可检查仍保留，未修改许可证或网卡标识。

16/16 已生成，13 张确定性检查通过；压铆螺母分散组、加强筋合件两张箭头偏小，卡箍的力矩文字需目视确认。此结果属于取景小批量测试，未做全量，也不等于生产工艺已经验证。
