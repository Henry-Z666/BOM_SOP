# v0.2.0 — AI 审核、批量优化与原模板出品

## 更新内容

- 恢复真实 AI 图片审核，默认使用 `qwen3-vl-plus`。结构硬门不能由 AI 豁免；图片审核通过后自动采用，不通过或调用失败转人工复核。
- GUI 支持 DashScope Key 的 Windows DPAPI 加密存储；不将 Key 打入 EXE。
- 支持 BOM 多顶层 ASM 批次，保持每个根装配的独立版本、哈希和坐标系。
- 修复多批次全局任务索引，原生渲染器启动时校验任务身份。
- 辅助特征清理限定在当前可见分支，提前解析缺件；确定性缺件不反复重试。
- 原模板按主工序合并图片、最多六图自动排版并创建续页；交错输入不再打散同一主工序。
- 主工序名称取所属装配体；拆分安装动作不重复累计整行 BOM 数量，保留非整数原始数量。
- 构建隔离外部 DLL 搜索路径，并排除工具链的 ICU/UCRT 同名库，修复 EXE 的 QtCore 启动失败。

## 已有全量验证

2026-09-05 至 09-06 的源码运行处理了 536 个任务：406 张正式图片完成真实 AI 审核，347 张通过、59 张不通过，0 次调用失败。另有 2 张诊断预览、81 项缺件跳过、26 项占位、21 项未得到合格结果。347 张批准图片已按原模板形成 96 个主工序、120 页的初步成果。

85.47% 是本批 AI 通过率，不是准确率。尚未取得完整人工标注，因此不报告模型准确率。此次 EXE 发布不重新调用 AI，也不重复数小时的全量 Creo 渲染。

## 安装与使用

本次发布验证：270 项测试、65 项子测试通过；Java 分支清理回归通过；重新编译与 PyInstaller 构建成功；包内原模板、关键 Java 类及渲染入口哈希与源码一致。最终 EXE 后台入口启动及桌面主窗口创建、关闭验证通过。完整运行环境仍须按下述要求配置。

下载 Release 附件 `CreoSopAgent.exe`，核对同页 SHA-256。目标电脑仍须有 Creo/J-Link、JDK 和桌面 Excel；首次启动填写本机路径和许可。启用 AI 前填写自己的 DashScope Key，并确认图片可以发送给该服务。

EXE 不包含 Creo、Java、Excel、许可证、API Key、用户 BOM/CAD 或本次 SOP 图片。详细构建及使用步骤见 README。
