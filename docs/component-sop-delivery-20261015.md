# 部件式 SOP 与本次源码同步

2026-10-15 的最新出品为 40 个部件、51 页的 CAD 装配工艺卡（本地保留）。2026-10-23 将该成果、出版配方及此前尚未提交的架构改动一起整理入仓。

## 出版调整

参照用户指定的总装工艺卡，以部件、功能总成及明确的安装区域组织页面。原子安装步骤只用于本地 CAD 执行、检查和追溯，不再等同于出版页。紧固件和密封件归入对应部件；一张部件卡结合位置主图、必要的连接局部图、安装说明、物料及工具。

BOM 层次单元格的黄色填充定义整体来料边界。白色后代结合其黄色祖先判断是否属于内部制造，不能简单删除所有白色物料。出版时再次核对颜色边界、计料和实际 CAD occurrence；整体来料的名称栏显示黄色。

本版按用户要求只做主要 CAD 工艺，省略标签、现场照片、检查和包装等页。既有完整源数据仍保留在本地，未把本版描述为包含这些工艺的全流程工厂文件。

## 同步的代码能力

- 新版工艺资料解析、BOM 层级与来料边界、模型参数身份匹配和确认的模型替代绑定。
- CAD 尺寸和接收面驱动的取景、整体定位与局部连接、遮挡与薄盖板安装侧判定。
- 原生红色箭头、中文物料名称、位置数字气泡和完整文字力矩的布局及来源匹配。
- 常驻 Creo worker、源模型可见性恢复、接收件透明显示后的清理、姿态恢复及源文件哈希验证。
- BOM 出版覆盖、重复连接示例边界、末端包装可见性规则和部件式出版。

本次同步发现连续局部序列编译丢失上游颜色边界字段，已补齐传递，并保留缺失颜色证据时拒绝编译的行为。对应回归用例同时验证成功传递及缺失时拒绝。原生清理测试同步覆盖显式物理显示后的会话清理分支。

## 交付及复现边界

仓库保留 Excel、51 页预览、数量及颜色核对记录、图片哈希清单，以及 [出版脚本和实际模板](../scripts/cdu900/README.md)。脚本从原先被忽略的工作目录整理出来，模板和品牌图改用仓库内资源，构建器根路径改为相对脚本定位。

CAD 出图仍依赖本地 Creo、许可证、新 BOM/CAD 以及本地锁定的图谱和图片证据。仓库中的成品可直接查看；重新从 CAD 出图或重新编排完整实例需要本地输入，不把该产品配方冒充为任意产品的一键通用流程。


本次为源码和已有成品同步，不新增全量 Creo 实机运行，也不重新生成 Windows EXE。
