# 单图取景泛化第二版

用户要求继续泛化，保留单图，只有明确要求时做全量；本次仍为原 16 张分层小样本。

新编译任务使用 `single-image-anchor-fit/v2`，不读取上一轮逐张放大倍率。已有冻结任务仍可复现 v1。

- 安装方向仍来自 CAD 接口法向。
- 对多件长条分布，读取 moving_bounds 并集的长轴，向该方向倾斜相机，同时保持接口法向分量大于 0.35，避免接口侧视成一条线。
- 原生 Java 在锁定安装锚点附近寻找真实曲面，以最近距离加曲面尺度惩罚进行选择；不改变箭头的原始 CAD 锚点。
- 子装配递归检查内部零件曲面，选中接口所在实体，而非强制纳入整个装配。
- 部分曲面最近点接口返回空值时，用真实曲面包围范围判断取景距离。
- 无可用曲面接口的导入件采用原生待装件取景回退，写入 `.focus.json` 并打印回退原因；未更改模型、数量、可见集合或许可。
- 根据 torque_annotations.labels 自动为含力矩文字的步骤预留空间，无需逐张倍率设置。
- 取景在 Creo 内完成，仍仅固定中心方形输出，不做图片自适应裁切或 AI 图像改写。

范围：还没有实现完整遮挡评分，也不保证极远分散的小紧固件能在同一张图中达到近景大小。该类限制保留图面失败记录，不宣称检查通过。

实现位置：`installation_view.py`、`ArrowProjection.nearestInterfaceSelections`、`RenderAssemblyImage`。输出位于 `outputs/单图泛化取景测试-20261010`。
