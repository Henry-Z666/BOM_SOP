# 纯 BOM + Creo 装配 SOP 产品契约

## 事实来源

- BOM 是物料层级、数量、名称和工艺顺序的唯一业务事实来源。
- 锁定的最终 Creo 总装是 occurrence、装配约束、坐标、接收面和完整安装态的唯一几何事实来源。
- 每次运行记录 BOM、CAD 和最终总装 SHA-256；源 CAD 只读，运行前后哈希必须一致。

## 确定性规划

- occurrence 必须由 BOM 字段与 Creo 图谱唯一映射，不允许从自由文本猜测。
- 装配方向来自 Creo 原生约束/接收面；只有已测接收轴的正负号证据不足时，才接受结构化人工确认。完全缺失接收轴时保持待确认，不能由表单创建坐标。
- 爆炸只允许纯平移，不改变零件旋转；后续零件不得提前显示。
- 计划、依赖、可见集、变换、相机和箭头均写入版本化 Artifact，并由硬门校验。

## 固定双视角

- `fixed_123` 与 `fixed_456` 在根坐标系中预定义，运行时不得创建第三个相机。
- Creo 曲面方向只作为无符号轴；其正负号不视为可靠的“外侧”证据。以实体包围盒比较两个平移符号，并在同轴多接受件上最大化最小净分离量。
- 接口法向与展示爆炸轴分开记录：正常情况仍沿接口法向；只有细长件沿自身长轴伸缩，或零件具有明确侧向主跨度（长宽比至少 `3`）、接触点侧向偏置且法向平移仍与已装上下文显著重叠时，才允许在接受面内选择一个固定根轴做侧向平移。
- 对每个步骤，两台相机先通过接收轴绝对夹角和爆炸屏幕投影硬门，再以活动件相对已显示上下文的几何遮挡分数稳定排序；完全相同时固定优先 `fixed_123`。
- 选定结果在正式渲染前锁定。每个步骤只生成一个正式相机变体。
- 渲染后的图片告警不得切换相机、PAN、Zoom、取景策略或触发替代视角重渲染。

## 图片验收

- 机器校验只依据结构化装配审计、可见集、变换、相机、箭头和文件完整性证据。
- 已通过几何硬门的真实 Creo 图片可直接进入出版；构图类告警只记录诊断，不改写相机。
- 几何事实缺失、相机硬门失败、变换审计失败或图片缺失时停止该步骤并给出明确错误码。
- 箭头锚点可在同一锁定相机内进行有限确定性修正；不得借此改变视角或装配方向。

## 状态与交付

- 状态、Artifact 哈希、执行指纹和检查点保存在隔离运行目录与 SQLite 中，不依赖会话历史。
- 正式渲染前后及出版前必须复核输入清单中的 BOM 与全部 Creo ASM/PRT 哈希；文件集合或任一哈希变化都立即停止。
- 单步骤失败不阻塞无依赖关系的步骤；修订只重跑该步骤及依赖后代。
- 最终交付目录仅包含 `SOP.xlsx` 与 `步骤图片/`。
- 相同输入、配置和 Skill 版本必须产生相同计划、相机选择和执行指纹。
