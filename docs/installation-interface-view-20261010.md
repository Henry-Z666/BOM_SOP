# 安装接口取景

按用户要求取消完整部件必须入镜和只能使用两个固定视角的限制。

新增 `installation-interface-view/v1`。小安装件使用 Creo 原生选中零件缩放，承接大面不参加取景范围；大安装件优先使用同一 CAD 箭头锚点对应的原生接触面缩放。零件可见集合、安装位置和纯平移保持来源约束。

局部斜视角由安装面的根坐标法向和竖直参照确定，保存在任务的相机目录；验证器核对相机是否与该法向推导一致。允许大部件远端裁切，局部主体最低跨度为画面 30%，安装箭头仍需在画面内且方向正确。原固定视角保留，可用作定位图。

已实机生成两个单连接示例，来源是全量任务中的压铆螺母和焊接六角螺母。单连接示例明确只展示一个实例，不能替代整组物料数量。已有 584 张图片及 Excel 不会因代码改动自动更新，需要重新生成对应任务。

当前局限：接触面本身也是大平面时，原生面缩放仍可能过宽；分散安装点的正式连续工序需在步骤规划中拆分或增加局部图，不能直接改变已锁定步骤的可见集。整体定位图与局部图尚未自动配对。
