# 通用取景小批量验证记录

本轮使用“AI生成SOP外发资料”的锁定 CDU900 总装，未进行全量测试。全部新图是原生 Creo 图；隔离几何样本不代表已确认连续工艺的正式 SOP。

## 已建立的规则

- 输入由完整 occurrence、原生尺寸包围盒、约束安装点与法向构成，规则不含步骤编号或零件名称特例。
- 先核实当前可见零件和背景，再决定展示位移。缩短展示距离必须有全部背景 AABB 不重叠的保守证明；缺证据则保留原位移。
- 用法向厚度识别大型薄件的安装特征。分散位置生成整体定位和按真实锚点分组的局部图；局部组完整、无重复覆盖原工序所有位置。
- 同一 CAD 点的爆炸点、完成点及箭头头部进入保护范围，禁止为取景移动箭头端点。
- 原生背景差分排除红色 CAD 零件对箭头检测的干扰。证据摘要不一致即失败，不回退成纯颜色检测。
- 完整力矩文字与安装数量说明各有独立来源和通道。分组后标签未重新绑定时明确阻止扩展。

具体公式与默认版本见 [通用安装取景规则](../rules/adaptive-installation-framing.md)。

## 复现入口

使用 scripts/prepare_framing_samples.py 从 diagnostic_preview 计划选择小批量索引；默认 v15，最多 24 张（显式上限不超过 32）。样本选择记录原计划摘要、源索引及 production_eligible=false；无单样本倍率。按 native batch 运行，再使用 review.py 读取实际图与摘要执行验证，最后 scripts/build_framing_review.py 汇总同一工序的定位和全部局部组。

当前规则测试 26 项、原生验证测试 23 项、正式规划测试 27 项全部通过；另有 Java 编号布局的整组分离、引线交叉和 0.001/1/1000 缩放测试通过。原生 Java 构建成功。缩放测试不等于跨 CAD 单位的实机认证。


## v15 最终冻结回归
