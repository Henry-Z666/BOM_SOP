# Creo 装配 SOP：箭头生成与可迁移数据方案

## 结论

成熟的装配箭头方案不是“根据图片找一个位置画线”，而是**同一 CAD 锚点在爆炸态与安装态之间的几何投影**：

```text
稳定局部表面锚点
    ↓ 通过实际 occurrence 变换
爆炸态根坐标 ─────────→ 安装态根坐标
    ↓ 同一固定相机与构图投影
屏幕起点 ─────────────→ 屏幕终点（箭头头部）
```

跨产品可复用的是锚点选择规则、变换/投影算法、像素验收阈值和审计 schema；不可复用的是任一旧产品的锚点坐标、occurrence 路径、箭头端点或屏幕偏移。

## 1. 语义边界

箭头表达的是“待装件从爆炸位置移动到安装位置”的**真实安装向量**，不承担构图、相机、隐藏零件或纠正爆炸方向的职责。

| 要素 | 负责的问题 | 箭头不能替代 |
| --- | --- | --- |
| 阶段可见集 | 当前步骤的零件、接收件与未来件边界 | 用额外箭头解释未来零件 |
| 爆炸平移 | 待装件如何离开接收面、移动多远 | 通过弯箭头或视觉猜测修复错误平移 |
| 相机与构图 | 从哪里看、画面中显示多大 | 用屏幕偏移伪造 3D 安装关系 |
| 箭头 | 在最终画面中标示爆炸态到安装态的方向 | 代替 CAD 锚点和装配约束证据 |

正式箭头只接受根坐标中的纯平移证据；不得按屏幕鼠标坐标、包围盒中心、图像猜测或人工目测来决定端点。

## 2. 通用推导算法

### 输入

- 已锁定的最终 ASM、版本、哈希和根坐标系；
- 当前步骤的移动 occurrence、接收 occurrence 与阶段可见集；
- 当前步骤的根坐标纯平移向量 `t`；
- 一个已选定的产品固定相机与最终构图合同；
- 每个移动 occurrence 的候选实体表面与稳定局部点。

### 推导步骤

1. 为每个移动 occurrence 选择一个真实实体表面的稳定局部锚点 `p_local`；禁止使用包围盒中心。
2. 读取同一 occurrence 在安装态与爆炸态的实际变换 `T_complete`、`T_exploded`。
3. 计算根坐标端点：

   ```text
   p_complete_root = T_complete × p_local
   p_exploded_root = T_exploded × p_local
   ```

4. 验证几何恒等式：

   ```text
   p_exploded_root - p_complete_root = t
   ```

   且两个状态的 3×3 旋转矩阵相同。任何不相等都说明不是同一 CAD 点、变换错配或步骤不是纯平移，应阻断渲染。
5. 在同一固定相机、Zoom、PAN、阶段可见集和固定裁切条件下，将两个根坐标点投影为屏幕端点。
6. 以 `p_exploded_screen → p_complete_screen` 生成箭头；箭头头部必须在安装态终点。
7. 若箭头与零件、其他箭头或画框冲突，依次尝试：同一实体上的备选稳定锚点 → 经覆盖审计的同向箭头合并。不得修改端点所代表的安装语义。

## 3. 两阶段渲染与像素验证

推荐采用 V3 两阶段机制：

1. 生成**校准图**：仅用于读取 Creo 原生临时绿色箭头的最终屏幕端点；不发布。
2. 生成**底图**：没有临时图元，是唯一可发布的几何图层。
3. 对两张图执行同一固定裁切；在底图上按校准端点绘制最终箭头。

这样可将“几何真值”与“出版外观”分离：端点来自 CAD/Creo，线宽、颜色、箭头头和抗锯齿由可控的像素合成器统一处理。

建议的通用出版规则：绿色 RGB `(0,176,80)`、线宽 3 px、箭头头 13 px；最终固定裁切后每根未合并箭头长度保持在 24–420 px。它们是出版单位，不应随 CAD 尺寸或 Zoom 改变。

## 4. 可迁移数据包

### `arrow_policy/v1`（可跨产品复用）

```json
{
  "schema_version": "arrow_policy/v1",
  "geometry_policy": "same_cad_point/v1",
  "direction": "exploded_to_complete/v1",
  "anchor_priority": ["planar_interior", "cylindrical_side", "solid_descendant_surface"],
  "merge_policy": "same_direction_with_coverage_audit/v1",
  "pixel_style": {"rgb": [0, 176, 80], "width_px": 3, "head_px": 13},
  "length_px": {"min": 24, "max": 420},
  "overlap_policy": "reject_or_audited_merge/v1"
}
```

这些是方法与质量门槛；初始阈值应通过多个产品的试运行校准，而不是从水箱步骤数值复制。

### `arrow_projection_calibration/v1`（按环境复用）

应记录 Creo 版本、原生画布、固定裁切框、最终图像坐标系、校准图的颜色容差和连通域检测版本。它依赖输出环境；Creo 版本、分辨率、导出方式或裁切框变化后应重新验证。

### `arrow_audit/v1`（可积累、不可直接复用）

每个箭头至少记录：

- 覆盖的完整 occurrence 路径；
- 锚点所属实体、表面标识与局部坐标；
- 安装态/爆炸态根坐标及变换证据；
- 屏幕端点、像素长度、连通域、重叠检查；
- 合并状态、被覆盖对象和最终验收状态。

该数据适合用于统计哪些表面类型更稳定、哪些场景易重叠；不能把坐标、表面 ID 或端点直接搬到另一个产品。

## 5. 不可迁移数据

- 旧产品的局部锚点坐标、surface ID、实体路径与 occurrence 路径；
- 旧产品的爆炸向量、屏幕端点、箭头数量及合并决定；
- 旧产品的相机、Zoom、PAN 和裁切偏移；
- 从发布图片反向量得的箭头位置。

这些值依赖具体 CAD 拓扑、根坐标、阶段可见集和相机投影。新产品必须从其锁定的最终 ASM 重新解析 occurrence、表面与变换。

## 6. 常见失败与处置

| 现象 | 根因 | 正确处置 |
| --- | --- | --- |
| 箭头指向错误 | 爆炸态/安装态端点顺序颠倒 | 固定为 `exploded → complete`，并由箭头头部判定安装端 |
| 起终点漂移 | 两个状态用了不同局部锚点，或 occurrence 路径不一致 | 记录同一 `p_local`，验证端点差等于平移向量 |
| 箭头从零件中心穿出 | 使用包围盒中心或图像猜测 | 选择真实表面上的稳定锚点 |
| 多根箭头互相覆盖 | 未做屏幕投影布局评估 | 换备选锚点；仅同向且覆盖完整时才审计合并 |
| 箭头长度不稳定 | 依赖 CAD 长度或未在最终裁切后测量 | 在最终固定画框中按像素阈值验收 |
| 图像好看但不可审计 | 直接在图片上手工画线 | 使用校准图读取端点，并保留 `arrow_audit` |

## 7. 落地建议

新增一个 `arrow_planner`，职责仅为：选择/验证候选锚点、计算两态根坐标、生成投影审计，并在必要时提出备选锚点。它不修改相机、Zoom、可见集或爆炸向量。

每个新产品应先完成三类验证样例，再扩大批量：

- 多紧固件步骤；
- 刚性子装配整体移动步骤；
- 单件装配步骤。

每类均需通过同 CAD 点、端点差等于平移、固定画框内长度、方向、连通域数量和不重叠（或审计合并）检查。

## 一句话原则

**跨产品复用“同一 CAD 点如何变换、投影和验收”，不要复用“上个产品的箭头画在哪里”。**
