# Creo 装配 SOP：Zoom 语义经验总结

## 结论先行

在本流水线中，**Zoom 是构图尺度，不是相机、视角、爆炸距离或后处理裁切的替代品**。它只回答一个问题：在已锁定的阶段可见集与固定相机方向下，主体在画面中应占多大比例。

这一定义把常被混在一起的四类决策拆开：

| 决策 | 负责的问题 | 不应由它解决的问题 |
| --- | --- | --- |
| 相机（`fixed_123` / `fixed_456`） | 从哪个固定方向看，接收面是否可读 | 主体大小、偏移、爆炸效果 |
| 阶段可见集 | 当前安装步骤中什么应被看见 | 为了好看而保留未来零件 |
| Zoom | 主体在既定画幅中的尺度 | 改变视线方向或掩盖遮挡 |
| PAN / 固定裁切 | 在既定方向和尺度下校正画面位置、适配出版画幅 | 重新定义 Zoom 或动态追随几何 |

## 1. 语义边界

### 1.1 Zoom 以阶段为单位，而不是以总装为单位

每一步的焦点应是 `stage_visible_bbox/v1`：已完成件、当前移动件和必要接收件组成的阶段可见集。不能拿完整总装的中心、补偿值或 Zoom 直接复用到局部步骤。

这样处理的原因是：局部装配时，完整总装常远大于真实操作边界；沿用总装尺度会使零件、接收孔和箭头不可读。反过来，阶段 Zoom 只对该步骤合同负责，不应被当作产品级常量。

### 1.2 Zoom 不改变方向

正式步骤只允许 `fixed_123` 或 `fixed_456` 两个已标定方向。若接收面退化成细线、移动件被遮挡，先在这两个视角中重新选择；若两者都不满足可读性，应复核接收面、阶段可见集、爆炸向量和装配根坐标，而不是“转一点相机”或创建第三视角。

### 1.3 Zoom 不等于爆炸距离

爆炸距离由接收/接触面的根坐标法向决定，目标是区分待装件与安装位、形成适当箭头长度。Zoom 只控制画面尺度。两者耦合时容易产生误判：把零件拉远后再放大，虽然视觉上接近原图，却改变了箭头、间隙与安装语义。

### 1.4 Zoom 不等于导出后的缩放

正式图像应在 Creo 内完成 Refit、Zoom 和必要 PAN；出版层只使用约定的固定裁切框，且不检测几何、不二次动态裁切、不重采样、不放大。后处理缩放会破坏合同可重复性，也会让箭头像素规格失去稳定基准。

## 2. 推荐决策顺序

```text
锁定最终 ASM 与相机基准
        ↓
建立步骤前向可见集（不含未来件）
        ↓
选择 fixed_123 / fixed_456（先保证接收面和操作边界可读）
        ↓
按阶段可见集 Refit、居中
        ↓
确定 ZOOM（主体尺度）
        ↓
仅在允许时测量 PAN（画面位置）
        ↓
固定裁切、箭头像素校验、发布
```

关键经验是：**先语义、后构图**。如果先凭画面调 Zoom/PAN，再倒推可见集和相机，往往会得到“看起来合理、合同却不成立”的图。

## 3. 可执行规则

1. 每个步骤先以阶段可见集 Refit/中心化，再记录最终 `ZOOM`；不要沿用完整总装的 `CENTER` 补偿。
2. `fixed_123` 默认不写非零 PAN，只记录 ZOOM；它保持默认侧的稳定、可复现构图。
3. `fixed_456` 可记录 ZOOM 与 PAN，但 PAN 必须来自相同 Zoom 下的实测像素响应。`ZOOM=1` 的 PAN 系数不能外推到其它 Zoom。
4. 特写的首选手段是缩小阶段可见集并提高原生 Zoom，而不是增加相机方向或裁切后放大。
5. 每次更改 Zoom 后，都重新检查移动件、接收件、安装边界和箭头是否同时可读。
6. Zoom 值必须写入步骤相机合同，成为可重放输入；不要只留在人工操作记忆或 Creo 会话状态中。

## 4. 常见误区与纠正

| 现象 | 真实问题 | 正确处理 |
| --- | --- | --- |
| “把 Zoom 调大就能看到接收孔” | 接收面可能在当前相机下退化或被遮挡 | 在两个固定相机中重选，并检查接收面分类 |
| 局部步骤主体很小 | 焦点仍是完整总装 | 按阶段可见集 Refit 后再确定 Zoom |
| 从反面看画面偏了 | 456 侧构图偏移未按当前尺度测量 | 固定 Zoom 后做 PAN 探针并反解偏移 |
| 图中零件大但安装关系不清 | 用 Zoom 掩盖了错误的爆炸方向/距离 | 回到接收面法向和纯平移合同 |
| 发布图与 Creo 预览比例不一致 | 后处理做了二次缩放或自适应裁切 | 只用固定裁切，禁止重采样与动态裁切 |
| 同一合同复跑构图漂移 | Zoom/PAN/CENTER 未完整固化，或依赖会话状态 | 在合同中显式记录并在独立会话中复放 |

## 5. 验收清单

一张图可接受的最低条件：

- 相机精确等于已标定的 `fixed_123` 或 `fixed_456`；
- Zoom/PAN 仅用于构图，未改变相机方向；
- 焦点来自当前步骤的阶段可见集，而非完整总装；
- 移动件、接收件和安装边界在同一画面内可读，接收面未退化为细线；
- 阶段可见集严格满足前向安装语义，不包含未来件；
- 爆炸仍为沿接收面法向的纯平移，未因构图而改变；
- 输出采用固定画幅与固定裁切，未做检测几何的动态裁切或放大；
- 箭头经过像素级长度、方向、覆盖和不重叠（或已审计合并）校验。

## 6. 复盘模板

出现“画面不清楚”时，按以下顺序记录，不要直接把 Zoom 当万能旋钮：

1. 当前步骤的移动件、接收件与可见集是否正确？
2. 两个固定相机中，哪个能同时显示接收面与安装边界？
3. 接收面是否因坐标变换或面归类错误而退化？
4. 爆炸向量和距离是否让待装件、目标位与箭头可区分？
5. 阶段 Refit 后，Zoom 是否只是在补足主体尺度？
6. 若为 `fixed_456`，PAN 是否在当前 Zoom 下重新实测？
7. 固定裁切后，箭头及关键信息是否仍在最终 1600×1600 画幅内？

## 一句话准则

**相机决定“从哪里看”，可见集决定“看什么”，Zoom 决定“看多大”，PAN/裁切决定“放在哪里”；四者不可互相越权。**
