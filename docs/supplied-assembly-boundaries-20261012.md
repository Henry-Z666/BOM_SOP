# 直接发料组件与框架装配边界

## 原料规则

依据用户提供的 BOM 与工艺卡批注，新版 MBOM 层次列的实心黄色（RGB FFFF00）表示完整发料组件。立柱焊件、底盘焊件等保持原生 ASM 的刚性完整状态，内部白色材料不再生成制造或装配步骤，也不进入对应现场工艺卡物料表。橙色框架部件保留为工艺范围，不能提前把整个框架设为已装背景。边界外物料仍依照工位、工艺和 CAD 连接关系判断，不将“白色”或“焊件”名称单独当作通用工艺事实。

颜色由 XLSX styles/cell 样式读取，与 BOM 层级一起保存。`supplied_assembly_owners` 找到黄件内部行，`assembly_scope_frontier` 提供装配边界，草案、CAD 映射、正式规划统一使用该边界。已有无颜色资料沿用原规则。本产品 927 行中有 577 行落在完整发料组件内部；规划边界保留 350 行，含产品/部件范围和发料物料，重新规划形成 317 个工序（296 个 ready，21 个仍有资料或几何问题），原依赖循环消除。

## 连接和取景

连接紧固件根据两件完整组件的原生包围盒接合区域，以及当前已装件的实际约束引用选取。未来横梁上的紧固件不会提前加入柱脚步骤。侧面和底部安装轴分开取景；沿原生紧固件安装轴，用已显示 CAD 几何的包围范围选择较近外侧边界，加上零件特征尺寸余量，保证运动件露出。接合点和完整状态保持原 CAD 位置，只有显示用平移改变，旋转不变。

同一柱脚的三组底部组合螺栓具有相同原生模型和安装方向，采用一组代表安装图，图标题必须明确“底部共3组，示意1组”，表中数量保留三组。两侧紧固件分别实际出图，不以代表图代替不同规格或不同安装方向。该代表规则仅用于已有用户许可的等价紧固件，不自动推广到异形零件。

整体定位图以当前已装 CAD 实体包围盒做原生相机映射和居中缩放，不使用图片内容裁切。固定正方形输出维持 1600×1600。宏观定位与局部安装图在同一 SOP 页，名称气泡保持实心米黄色底、深色实心字，箭头保持加粗红色。
