# 包装末段与实际工艺图

包装应在装配、接线、检验完成后执行。BOM 行序不能直接成为时间顺序。

1. 以当前 BOM 的物料身份、颜色边界和当前工艺卡确定包装输入。黄色包装子项整件使用，其内部制造不展开。
2. 包装来料不得提前进入机械装配图的已完成可见集合。`exclude_terminal_context` 接收已明确识别的包装 occurrence，剔除提前可见的包装及其后代，同时保持上下文几何数组与 occurrence 一一对应。
3. 不能剔除本步移动件或接收件。涉及包装本身的动作归入最终包装阶段。
4. 珍珠棉摆放、袋体防护、干燥剂放置等手工作业，采用同产品新工艺卡已有的实际图示和文字；不强制套用刚性机械插入动画。保存来源文件哈希、工作表、图示及当前 BOM 用量。其他机械工序不据此豁免出图检查。
5. 合并重复步骤时，材料代码、名称、单位、数量及真实 CAD occurrence 转移到对应工艺页，保持唯一计量。旧任务留档为已替代，不改为“通过”。
6. 修改后的可见性契约必须重新原生出图。核验实际执行记录中的可见项、排除项和图像哈希，不能将改契约前的旧图直接复用。

本产品依据：新总装工艺卡“打包-1”至“打包-4”；当前 BOM 包装件及其子项。工艺卡明确干燥剂放置、四周珍珠棉保护、顶部盖顶盖、打包带和外袋及标签步骤。产品实例映射见本次输出的“包装阶段修正规则.json”。
