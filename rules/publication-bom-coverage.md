# 出版范围和物料完整性

对新BOM的每一行出具覆盖账，不能以CAD未找到独立模型为由删除必要物料，也不能只把规划阶段的“跳过”数组清空。

1. 先解析层次单元格实际底色。最外层黄色是供应成品边界，内部白色及嵌套黄色不展开。普通橙色或白色构造层级须保留必要装配。
2. BOM子项用量是每个父项的用量。构造父项数量大于1时，逐级乘算整机用量；例如22组螺栓组合对应22件螺栓、44个大垫圈、22个螺母。
3. 原生实例不得重复分配。安装在整机上的六个螺栓与随附件另配的四个螺栓是不同用量；不能复用同一CAD实例证明备件已经配齐。
4. 线缆、软管、标签等手工作业保留当前BOM的完整名称、规格、用量和单位，并引用实际工艺卡。独立CAD未映射或映射歧义须如实记载，不伪造实例，也不把“歧义”改写为“不存在”。
5. 用质量计量的板材、按面积计量的成形件原材、已包含在装配泵型号中的裸泵，分别记录上游原材或物料组成与实际安装父项的关系；避免再次制造或重复安装同一物体。
6. 普通构造输出的子项必须先于整体安装。补充出图的晚到顺序不能成为出版工序顺序。运输包装必须放在整机装配及出厂保压之后。
7. 一页最多四图、九行物料、十一行控制要点；长文字与材料表分续页，同一物料只计一次。米、平方米、千克、升等单位必须可见。

原生局部剖示仅隐藏遮挡外壁，不改变CAD几何或安装姿态。必须同时有完整定位图，并在局部图标题和控制要点中明确“遮挡外壁隐藏”；不能把展示性隐藏与BOM颜色排除混为一谈。

不得为凑图位引用不相关工艺图。资料仅提供辅料用量而未提供安装位置图时，明确列为配套备料页；已有源图保留来源、文件哈希和裁切区，旧图的物料表不作为新版计量依据。

同一张图中相同物料重复出现时，可使用一个中文名称气泡并明确“本图N件”。名称气泡锚定真实实例，同时记录所代表的完整实例集合；所有零件、各自安装箭头和逐实例可见性证据仍须完整保留。这只是文字去重，不能借此减少实际工序用量或跳过实例检查。定位图的空间数字编号仍单独保留。
