# 有头紧固件装入侧

仅对 CAD 参数明确给出公称直径和长度、BOM 名称明确为普通有头螺钉或螺栓的刚性零件，使用原生 MATE/MATE_OFF 接触面和实体包围盒证明头侧。不得将 INSERT 轴向符号直接当作装入方向。

接触面法向必须平行、接触面位于真实接收实体范围内、法向间距符合约束偏移。以接触面为界，短段须符合头部和垫圈尺寸，长段须符合杆部长度，且两者有明确差异。满足这些条件时，短段侧为退出展示侧，安装箭头从该侧指回完整安装位置。原生姿态和旋转不变，只允许平移。

沉头、肩部、定位、焊接紧固件，螺母、垫圈，斜向投影无法消除包围盒歧义以及多个约束互相矛盾的情况，均不使用此推断。

推断结果保留源总装哈希、原生约束、接触面、头侧与杆侧尺寸。变更方向后必须重新原生出图，重新验证移动零件可见性、接收位置、同一点箭头、平移姿态和尺寸。原方向的图片不能沿用。

对细节图中紧固件过小或被遮挡的失败项，可使用原生尺寸限制展示拆开距离：下限为接触面至杆端长度加半个公称直径，上限取不小于该下限的 1.5 倍公称长度或 3 倍公称直径。距离仍沿已证明的头侧，不改变安装姿态。保留原距离、实际距离和尺寸依据；只有重新原生出图并通过可见性、尺寸及箭头检查后才可采用。已有清晰图片无需因此重出。
